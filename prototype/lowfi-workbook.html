图 1：在桌面端打开表格簿“周报”，当前是笔记表“本周”

  1. 1顶部标签页显示簿名“周报”，带表格簿图标。一个表格簿只占一个标签页，切换表不会新开标签页。

  4. 4表标签：类型图标加表名（≡ 笔记，✱ 思维导图，⇢ 流程图）。当前表白底、加粗，底部有一条强调色线。点击切换；Ctrl+PageUp 和 Ctrl+PageDown 切换到上一张或下一张表（不会和现有快捷键冲突）。每张表各自自动保存；切换表的行为和现在切换标签页一致：思维导图和流程图的缩放、折叠状态按表保留，笔记的光标和滚动位置不单独保留。
  5. 5状态栏显示当前这张表的统计：笔记表显示字数和行列，导图和流程图表显示节点数和缩放比例；保存状态也对应当前这张表。
  6. 6打开表格簿时，停在本机上次看的那张表；第一次打开时停在第一张。

图 4-c：“上线流程”的反向链接

  1. 1补全：选中表时，写入的格式和现在一样，即 [[本周]]；只有重名时才写成 [[周报.book/本周]]。思维导图和流程图表照常带 .mind 或 .flow 后缀。表格簿本身也出现在补全里，写入 [[本地化方案.book]]。

5. 在表格簿里用 AI 生成

在笔记表上用 AI 生成思维导图或流程图时，结果作为草稿表放进同一个表格簿。生成过程、停止、保留、丢弃、重新生成都沿用现有的草稿流程。

图 5：在“本周”上右键 →“用 AI 生成思维导图”之后

  1. 1顶部工具条和现在的 AI 草稿标签页一样：生成中可以停止；生成完可以保留、丢弃或重新生成。
  2. 2草稿表加在最后，虚线边框并带“草稿”标记，名称是“来源表名 思维导图”（或“流程图”），重名时加序号。“保留”后成为正式的表（写入文件），“丢弃”后标签消失，切回来源表。
  3. 3入口：表标签右键菜单（图 2-b，用整张笔记生成），以及笔记表里选中文字后右键的“用选中文字生成思维导图 / 流程图”，结果都放进当前表格簿。
  4. 4草稿没保留时关闭表格簿，和现在关闭草稿标签页一样，草稿直接丢弃（磁盘上还没有它的文件），其他表照常保存。

7. 磁盘上的样子（不是界面，供确认存储规则）

工作/
├─ 读书笔记.md
├─ 上线流程.flow.mmd
└─ 周报.book/                ← 以 .book 结尾的文件夹就是表格簿
   ├─ .book.json            ← 只记录表的顺序
   ├─ 本周.md
   ├─ 本周.assets/          ← 附件照常放在旁边
   ├─ 目标拆解.mind.mmd
   ├─ 发布流程.flow.mmd
   └─ 上周.md
{
  "version": 1,
  "order": [
    "本周.md",
    "目标拆解.mind.mmd",
    "发布流程.flow.mmd",
    "上周.md"
  ]
}
  1. 1每张表都是普通文件：历史版本、Git 和 WebDAV 同步、全文搜索、回收站都按单个文件处理，不需要特殊对待。
  2. 2“上次停在哪张表”只存在本机，不写进 .book.json，避免多台设备互相改它造成同步冲突。
  3. 3对不上时：文件夹里有、清单里没有的表追加到最后；清单里有、文件已经不存在的条目忽略；.book.json 缺失或损坏时，按文件名排序，下次调整顺序时重新写入。
  4. 4从回收站恢复一张表时，放回原来的表格簿，排在最后；如果表格簿也已经被删除，会重新建出这个簿，只包含这一张表。
