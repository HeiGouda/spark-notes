当两台电脑在两次同步之间修改了同一篇笔记，就会产生冲突。处理原则只有一条：两份都保留。远端版本保存为原文件，本地版本另存为“笔记名 (冲突 电脑名 日期).md”，

同步规则

  • 只传输有变化的文件
  • 冲突时两份都保留，由我手动合并
  • 网络中断后，下次同步自动续传
索引、历史版本、回收站只留在本机，不参与同步。
  • 基准状态保存在 .spark/sync.db，不上传
  • 协议细节参考 坚果云 WebDAV 说明 #同步

核心判断

用上次同步时的状态作为基准，和本地、远端做三方比较 Enter 确定 · Esc 取消 ：

/// 决定单个文件的同步动作fn decide(local: &State, remote: &State, base: &State) -> Action {    match (local.changed_since(base), remote.changed_since(base)) {        (false, false) => Action::Skip,        (true,  false) => Action::Upload,        (false, true)  => Action::Download,        (true,  true)  => Action::KeepBoth, // 冲突：两份都保留    }}

远端文件用 ETag 判断是否变化，本地用内容哈希。相关笔记：编辑器选型、性能指标

  2. 用户名应填写注册时的邮箱。
